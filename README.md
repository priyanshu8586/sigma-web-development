# Sigma Web Development

My learning journey through the **Sigma Web Development Course by CodeWithHarry**. This repository holds my lesson practice files and exercises as I learn HTML and CSS, with JavaScript coming next.

## What's inside

| Folder | Topic |
|--------|-------|
| `Lassan1` | HTML basics: a bookmark page |
| `Lassan2` | Images, ordered and unordered lists |
| `Lassan3` | HTML forms: a student application form |
| `Lassan4` | Inline and block elements, plus a first small project |
| `Lassan5` | `id` and `class` attributes |
| `Lassan6` | Images, video and media, plus a media project |
| `Lassan7` | Three ways to add CSS: inline, internal and external |
| `Lassan8` | CSS selectors |
| `Lassan9` | Fonts and text properties |
| `Lassan10` | CSS units |
| `Exercise1` | Practice exercise 1 |
| `Exercise2` | Practice exercise 2 |

## Tech used

- HTML5
- CSS3

## How to run

1. Clone the repo:
   ```bash
   git clone https://github.com/priyanshu8586/sigma-web-development.git
   ```
2. Open any folder and double-click its `index.html` in your browser.

No installs or build steps are needed.
